AstroForge

Manuel utilisateur — v1.5

Traitement d'images astronomiques : ciel profond, planétaire, finition

Python · Qt (PySide6) · fichiers .ui de Qt Designer · IA locale

1. Présentation

AstroForge est un logiciel libre de traitement d'images astronomiques organisé en quatre onglets : deux modes de travail (ciel profond, planétaire), une partie de finition commune et une page de configuration des profils d'équipement. Chaque étape de traitement propose plusieurs algorithmes, des paramètres réglables avec aperçu live, et des profils enregistrables (le profil « standard » contient les valeurs par défaut).

2. Installation

2.1 Prérequis

  • Python 3.10 ou plus récent (Windows, macOS ou Linux).
  • Les paquets de requirements.txt : PySide6, numpy, scipy, opencv-python, astropy, Pillow, matplotlib.

2.2 Installation standard

python -m venv .venv
# Windows : .venv\Scripts\activate    Linux/macOS : source .venv/bin/activate
pip install -r requirements.txt
python main.py

2.3 Scripts de lancement tout-en-un

launch.bat (Windows, double-clic possible) et launch.sh (Linux/macOS) créent l'environnement virtuel, installent les dépendances manquantes puis lancent le logiciel.

2.4 Exécutable autonome

build_exe.bat   (Windows)   →  dist\AstroForge\AstroForge.exe
./build_exe.sh  (Linux/mac) →  dist/AstroForge/AstroForge

Ces scripts utilisent PyInstaller et embarquent les interfaces. main.py --selftest vérifie une installation sans ouvrir la fenêtre.

3. Prise en main

3.1 L'interface

Quatre onglets : Ciel profond, Planétaire, Finition (commune) et Configuration. Chaque mode combine une colonne de paramètres (gauche), un aperçu Avant / Après / Côte à côte (centre) et la zone d'exécution avec journal et barre de progression (droite).

3.2 Aperçu live

Tout réglage déclenche, après ~0,45 s, le recalcul de l'aperçu sur une copie réduite de l'image. La case « Étirement auto (affichage) » révèle les données linéaires ; elle ne modifie pas les données exportées.

3.3 Profils de paramètres

Chaque groupe de réglages possède une barre [profil ▾] [💾 Enregistrer] [↺ Standard]. Le profil « standard » (valeurs par défaut) est protégé ; créez autant de profils que nécessaire — un JSON par profil dans profiles/.

3.4 Page Configuration

Créez un profil par matériel : caméra (pixel µm, résolution, température capteur, matrice de Bayer), télescope (ouverture, focale), réducteur de focale (case + facteur), mode de travail et pollution lumineuse (Bortle 3-4 à 9 — une force de débruitage est suggérée). La focale effective, l'échantillonnage (″/px) et le champ de vue sont recalculés en direct. Cases à cocher d'astrométrie : « solve-field (astrometry.net) » et catalogue CSV par défaut. Deux boutons clés :

  • « 🌐 Générer le catalogue Gaia pour ce champ » : télécharge une fois les étoiles Gaia DR3 (positions + magnitudes G/BP/RP) couvrant le champ de vue de votre profil.
  • « 🔍 Déterminer la focale automatiquement » : résout une image de votre matériel et déduit la focale (f = 206 265 × pixel / échelle) — utile après un changement de réducteur.

4. Mode ciel profond — workflow complet

4.1 Chargement et calibration (groupes 1-2)

Ajoutez les brutes (FITS, TIFF, PNG, RAW) et choisissez la matrice de Bayer (RGGB, BGGR, GRBG, GBRG) pour les capteurs couleur. Désignez les dossiers de bias, dark, flat et dark-flat : les masters sont créés (médiane avec rejet sigma) et la calibration applique (L − bias − k·dark) / flat avec mise à l'échelle du dark.

4.2 Pixels défectueux (groupe 10) v1.3

Trois cases : correction globale, détection automatique (sur le master dark/flat, σ-MAD) et correction des colonnes/lignes mortes (restaurées par les voisines). Une carte de pixels défectueux externe (FITS/PNG où > 0,5 = défaut, ou fichier texte « x,y ») peut être fournie.

4.3 Alignement & Drizzle (groupe 3)

Trois méthodes d'alignement :

  • Phase (translation + rotation) : corrélation de phase passe-haut — rapide et robuste ;
  • Étoiles (similitude) : appariement d'étoiles — rotation + échelle + translation, sans distorsion polynomiale ;
  • Plate solving + distorsions (poly) v1.5 : appariement d'étoiles puis ajustement polynôme de degré ≤ 3 des coordonnées — corrige les distorsions optiques/atmosphériques propres à chaque pose (ré-association mutuelle itérative, seuils 8→5→3 px, degré choisi au meilleur résidu).

Le drizzle (×2 ou ×3, pixfrac réglable) reconstruit l'image à plus haute résolution en profitant du dithering entre les poses.

4.4 Empilement (groupe 4)

Sept algorithmes : moyenne, médiane, sigma-clipping, winsorisé, rejet min/max, linear fit (mise à l'échelle de chaque frame sur l'image médiane, rejet au-delà de k·σ) et MAD clipping (médiane absolue). Les deux derniers éliminent satellites et traces cosmiques — testés : résidu 0,000 là où la moyenne simple laisse 0,056.

4.5 Traitement (groupes 5-6) et couleurs

Extraction de gradient (polynôme 2D degré 1-5 ou RBF ; soustraction ou division), débruitage (non-local means, bilatéral, médiane, ondelettes — ou IA locale), déconvolution Richardson-Lucy, netteté. Groupe 8 : calibration couleur sur le fond du ciel, neutralisation du fond et SCNR vert.

4.6 Calibration photométrique des couleurs — PCC v1.5

Résolvez d'abord le champ (groupe 9), puis cliquez « Calibration photométrique des couleurs (étoiles Gaia) » : les étoiles détectées sont appariées au catalogue ; les flux mesurés par canal sont comparés aux couleurs BP/RP de Gaia et les canaux R et B sont corrigés pour que les couleurs stellaires mesurées retrouvent celles du catalogue. Le journal affiche kR, kB et le nombre d'étoiles utilisées.

4.7 Astrométrie et photométrie (groupe 9)

Plate solving : solve-field (si installé et coché) ou solveur interne (appariement de motifs contre le catalogue local, WCS TAN). Le résultat (échelle, centre, nombre d'étoiles, RMS) s'affiche et le WCS est inscrit dans le FITS à l'export. Photométrie d'ouverture : CSV (x, y, flux, mag, zero point calibré). Photométrie différentielle v1.5 : la magnitude de la cible (étoile la plus proche des coordonnées RA/Dec saisies, sinon la plus brillante) est mesurée par rapport à la moyenne d'un ensemble d'étoiles de comparaison du catalogue — le zero point et l'extinction s'annulent. Export CSV : dmag ± erreur.

4.8 HDR, IA et processus automatique (groupes 7-8 de la liste d'étapes)

La fusion HDR (Mertens) combine plusieurs empilements d'expositions différentes. La liste « Processus de traitement automatique » organise les étapes (haut/bas, activer/désactiver) et s'enregistre/recharge en JSON.

5. Mode planétaire — workflow complet

5.1 Source (groupe 1)

Chargez une vidéo (SER lu nativement 8/16 bits mono/Bayer/couleur ; AVI/MP4 via OpenCV) ou une série d'images. Le tri qualité (style AutoStakkert!) note chaque frame par le contraste local haute fréquence et ne garde que les N % meilleures.

5.2 Dérotation et alignement (groupe 2)

Dérotation du champ (automatique par estimation de rotation, ou manuelle en °/min × intervalle), puis alignement par l'algorithme au choix v1.3 : Phase (rapide), Limbe (précis) — corrélation sur les contours du limbe, idéale pour Jupiter/Saturne — ou Étoiles (large champ). L'alignement multipoint (champ de décalage lissé) est appliqué par l'empilement AutoStack.

5.3 Empilement, couleurs (groupes 3 + aberration chromatique)

Choisissez AutoStack (AS!-style) v1.4 (qualité → sélection → alignement multipoint → moyenne), la moyenne simple, la médiane ou le sigma-clipping. L'alignement des canaux R/B recadre la chromatie planétaire ; la correction d'aberration chromatique radiale (sliders R/B) v1.3 se règle en aperçu live.

5.4 Accentuation et débruitage — méthode Registax (groupe 4)

Les 6 sliders d'ondelettes à trous reproduisent les couches de Registax6 (gain 0-3× par couche, du détail fin au large) ; le slider « Débruitage (ondelettes Registax) » v1.4 applique avant eux un seuillage doux par ondelettes. Tout se voit en direct dans l'aperçu.

5.5 Fausses couleurs et film (groupes 6-7)

Palette solaire (ou Inferno, Turbo…) pour les images N&B du Soleil. Le film stabilisé : recadrage commun automatique (l'image ne « danse » plus), MP4/AVI/GIF, FPS et qualité réglables. L'IA locale (débruitage, super-résolution) s'applique en un clic sur l'aperçu.

7. IA locale

  1. Modèles ONNX : déposez un .onnx (+ JSON de config optionnel) dans models/ai/ — inférence par tuiles avec fondu, GPU automatique si disponible.
  2. Outils externes : bouton « Configurer les outils IA… » — chemins de GraXpert (denoise + fond) et StarNet2/DeepSNR. Cosmic Clarity n'est pas automatisable (flux interactif) : utilisez-le à part puis rechargez sa sortie.
  3. Algorithmes classiques intégrés : aucune IA requise.

8. Formats et matrices de Bayer

Lecture : FITS (8-32 bits, mono/RGB), TIFF/PNG/JPEG (8-16 bits), RAW APN (avec rawpy), XISF (non compressé et zlib), SER (8-16 bits), AVI/MP4. Écriture : FITS float32 et XISF Float32 avec en-tête complet (NCOMBINE, pose totale, date, objet, filtre, instrument, WCS avec distorsions SIP), TIFF 16 bits ou 32 bits flottant, PNG 8/16 bits, JPEG 95 %, MP4/AVI/GIF, SER (avec horodatage). Matrices de Bayer : RGGB, BGGR, GRBG, GBRG — choix manuel ou détection automatique pour les RAW.

10. Session et bibliothèque de masters

Importer une session (tri auto)… (Ciel profond) lit les en-têtes FITS/XISF (IMAGETYP, EXPTIME, GAIN, température, binning, filtre, objet) — ou, à défaut, les noms de fichiers et dossiers — et regroupe les lumières par objet · filtre · pose · gain, chacune avec ses bias, darks, darks de flat et flats compatibles. Choisissez le groupe : listes de lumières et de calibration sont remplies.

Bibliothèque… : les masters calculés peuvent être enregistrés (« Enregistrer les masters calculés dans la bibliothèque ») puis réutilisés automatiquement (« Compléter avec la bibliothèque de masters ») selon pose, gain, température, binning, taille et filtre. Un dark de pose différente est mis à l'échelle automatiquement (dark − bias) × facteur optimisé.

Capteur couleur : la liste Sortie propose RGB, Ha seul ou OIII seul (filtres duo-bande Ha/OIII), extraits des photosites de la matrice de Bayer.

11. Analyse des brutes, poids, normalisation et multi-nuits

Analyser les brutes… mesure pour chaque image le nombre d'étoiles, la FWHM et l'excentricité (moments adaptatifs), le fond et le SNR ; les images aberrantes (nuages, traînées, mise au point) sont décochées. Pondération : Aucune, SNR, FWHM ou Mixte — les poids sont utilisés par l'empilement et le drizzle.

Outils › Empilement multi-nuits : chaque nuit est calibrée avec ses propres masters, puis toutes les images sont alignées sur une référence commune, normalisées localement (cartes de fond et facteur de transparence) et empilées avec rejet.

12. Finition avancée

Banque de filtres : GHS (étirement hyperbolique généralisé : D, b, SP, LP, HP) et arcsinh (préserve les couleurs) avec histogramme, réduction d'étoiles, débruitage de chrominance. Tout filtre peut être appliqué à travers un masque (luminance, fond, étoiles, sans étoiles, plage) avec flou et inversion. Séparer les étoiles… charge une image sans étoiles (StarNet, GraXpert) : le fond est traité seul puis Recombiner rajoute les étoiles (screen ou addition).

Aperçu : zoom (ajuster, 50 % à 400 %, molette, déplacement à la souris), valeur du pixel sous le curseur, médiane, bruit et SNR en direct.

14. Ligne de commande, langue, GPU, mises à jour

astroforge --help (ou python -m astroforge) : sous-commandes sort, analyze, stack, multinight, solve, annotate, compose, batch, live, script, info. Exemple : astroforge stack --session D:\M31 --weights Mixte --drizzle 2 -o M31.fits.

Langue / Language : menu de la fenêtre principale (français, anglais) ; appliquée au redémarrage.

Configuration › Performances & mises à jour : accélération GPU (CuPy) pour l'empilement, adresse du manifeste de mises à jour (vérifié au plus une fois par jour, rien n'est installé sans votre accord).

15. Installation par pip et installeurs

pip install . installe le programme (commandes astroforge et astroforge-gui). Options : [astro] (photutils, astroalign, astroquery), [ia] (onnxruntime), [raw] (rawpy, lz4, zstandard), [gpu] (CuPy), [dev] (pytest, ruff, PyInstaller). Installeurs : Windows (AstroForge-…-windows-setup.exe : Python embarqué, installation pour tous les utilisateurs ou pour vous seul, menu Démarrer, « Ouvrir avec » pour .fits/.xisf, désinstallation propre ; version portable .zip), macOS (.dmg signé et notarisé si un certificat Developer ID est fourni), Linux (AppImage) — voir packaging/.

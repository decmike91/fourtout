1. Installer et lancer AstroForge

1.1 Ce que fait AstroForge

AstroForge est un logiciel de traitement d'images astronomiques écrit en Python, qui fonctionne entièrement en local (aucun envoi de vos images sur Internet). Il s'organise en quatre onglets, visibles en haut de la fenêtre :

OngletRôleMatière première
Ciel profondCalibration, alignement, empilement, gradient, débruitage, IA, astrométrieFichiers FITS/TIFF/PNG/RAW : des dizaines de poses unitaires
PlanétaireClassement qualité, dérotation, alignement, empilement, ondelettes, film stabiliséVidéos SER/AVI/MP4 ou images APN
Finition (commune)Tonalité type GIMP, géométrie, netteté, recalcul, exportUne image déjà empilée, de n'importe quel mode
ConfigurationProfil d'équipement (caméra, télescope), catalogue Gaia, focale automatiqueLes caractéristiques de votre matériel

L'onglet Configuration nourrit les trois autres : le profil y détermine le catalogue d'étoiles, la taille de pixel et le mode par défaut. On le remplit une seule fois, au début du chapitre 3.

1.2 Installation pas à pas

① Installer Python — il faut Python 3.10 ou plus récent. Sous Windows, cochez « Add Python to PATH » pendant l'installation.
② Créer un environnement et installer les dépendances — dans un terminal, depuis le dossier d'AstroForge :
python -m venv .venv
# Windows :  .venv\Scripts\activate        Linux / macOS :  source .venv/bin/activate
pip install -r requirements.txt
③ Options recommandées — pip install rawpy si vous voulez charger les RAW d'appareil photo (CR2/CR3/NEF/ARW/DNG…), et pip install onnxruntime pour les modèles d'IA locaux.
④ Vérifier l'installation — python main.py --selftest contrôle tout le noyau sans ouvrir l'interface ; python tests/smoke.py exécute la batterie complète de tests.
⑤ Lancer — python main.py. En pratique quotidienne, préférez les lanceurs launch.sh (Linux/macOS) ou launch.bat (Windows, double-clic possible) : ils créent l'environnement, installent les dépendances manquantes et démarront le logiciel. Pour distribuer un exécutable autonome : build_exe.sh / build_exe.bat produisent dist/AstroForge.

1.3 Visite guidée de l'interface

Trois éléments reviennent dans tous les modes ; il faut les connaître avant de commencer :

  • L'aperçu live. Chaque groupe de réglages recalcule un aperçu environ 450 ms après votre dernier geste, sur une copie réduite de l'image. Vous voyez l'effet immédiatement, avec la bascule Avant / Après / Côte à côte et un étirement automatique commutable — indispensable pour juger une image FITS, dont les données brutes restent volontairement sombres (voir encadré).
  • Les barres de profils. Chaque groupe (alignement, empilement, traitement, IA, ondelettes, animation…) porte une barre [profil ▾] [💾 Enregistrer] [↺ Standard] : le profil Standard contient les valeurs par défaut, et vous pouvez créer vos propres réglages nommés (un JSON par profil, dans profiles/).
  • Les traitements en thread. Les opérations lourdes tournent en arrière-plan : l'interface reste réactive et vous pouvez préparer l'étape suivante pendant qu'une pile se calcule.
Astuce. Les menus Fichier (Quitter, Ctrl+Q) et Aide (À propos) complètent l'interface. Tout est reproductible : chaque chaîne de traitement peut être enregistrée et rejouée en batch — c'est l'objet du chapitre 10.

2. L'ordre des opérations : la logique d'ensemble

2.1 Pourquoi l'ordre compte plus que les réglages

Un traitement astronomique n'est pas une liste d'effets appliqués dans n'importe quel ordre : c'est un entonnoir. On élimine d'abord les défauts instrumentaux, puis on accumule le signal, puis seulement on embellit. Inverser deux étapes ne « dégrade » pas seulement le résultat — cela rend certaines corrections impossibles. Trois principes suffisent à retenir tout l'ordre :

  • Réparer avant d'aligner. Les pixels morts, colonnes d'amp-glow et poussières du flat sont des défauts fixes du capteur : on les corrige pendant la calibration, avant tout déplacement d'image. Après l'alignement, un pixel mort « bouge » et devient une tache multipliée par chaque frame.
  • Aligner avant d'empiler. L'empilement additionne ou moyenne les pixels ; si les étoiles ne sont pas superposées, on additionne du flou. Toute la géométrie (translation, rotation, distorsions) se règle donc avant la combinaison — et drizzle s'insère exactement là.
  • Embellir après avoir empilé. Le bruit se traite quand le signal est déjà accumulé (le stack a gagné en rapport signal/bruit) ; le gradient se modélise une fois les frames fusionnées ; la couleur, l'IA et l'étirement viennent en dernier, car ce sont des opérations esthétiques qui doivent rester réversibles.

AstroForge impose implicitement cet ordre : l'onglet ciel profond lit ses groupes de haut en bas, et le bouton ▶ Traiter (pleine résolution) et exporter… exécute la chaîne complète dans le bon sens. Le tutoriel suit exactement ce fil.

2.2 Le même entonnoir, côté planétaire

En planétaire, la matière première est une vidéo : l'entonnoir est le même, mais l'« étape calibration » est remplacée par le classement qualité — on élimine d'abord les frames floues (turbulence), on tient compte de la rotation du champ propre aux planètes, puis on affine l'alignement et on révèle les détails aux ondelettes une fois le signal empilé.

Deux erreurs classiques. ① Appliquer un débruitage fort avant l'alignement : l'algorithme lisse justement les étoiles qui servent de repères, et l'appariement se dégrade. ② Exporter en JPEG 8 bits puis « retendre » dans l'onglet Finition : toute information écrasée est perdue. Restez en FITS/TIFF 16 bits tant que la chaîne n'est pas terminée (voir chapitre 8).

2.3 Aperçu rapide contre calcul complet

Presque chaque groupe possède deux vitesses : l'aperçu live (image réduite, ~450 ms, réglages visuels) et le traitement pleine résolution (bouton ▶ Traiter…, minutes, fichier final). La bonne habitude : régler tout le groupe en aperçu, ne lancer la pleine résolution qu'une fois la chaîne entière réglée. Le chapitre 4 détaille groupe par groupe.

3. Configuration : décrire son matériel (profil d'équipement)

3.1 Créer le profil — cinq minutes qui servent à tout

L'onglet Configuration décrit votre matériel une fois pour toutes ; les autres onglets s'en servent (taille de pixel, catalogue d'étoiles par défaut, solveur). La démarche, reprise de l'aide intégrée (« Comment ça marche ») :

①Remplir « 1. Profil d'équipement ». Caméra, Pixel (µm), température capteur (°C), Résolution (px), Matrice de Bayer (Aucune (mono) / RGGB / BGGR / GRBG / GBRG) ; Télescope, Ouverture (mm), f= (mm) ; le cas échéant Réducteur de focale et son facteur (×) ; le Mode (Ciel profond / Planétaire) et le niveau de pollution lumineuse (Bortle 1 à 9, par exemple « Banlieue (Bortle 5-6) »).
②Enregistrer. Bouton 💾 Enregistrer… : créez un profil par matériel (par caméra, par télescope, par réducteur). Supprimer efface le profil courant.
③Lire les valeurs calculées. La focale effective (focale × facteur du réducteur), l'échantillonnage (″/px) et le champ de vue sont recalculés en direct pendant la frappe.
④Régler « 2. Astrométrie ». Cochez Utiliser solve-field (astrometry.net) s'il est installé si vous avez installé astrometry.net (le plus robuste) ; sinon le solveur interne utilisera le catalogue CSV — renseignez le Catalogue par défaut (ex. profiles/gaia_mon_champ.csv) et la Magnitude limite.

3.2 Ce que le profil calcule pour vous

Deux nombres pilotent toute l'astrométrie et le choix de drizzle :

échantillonnage e (″/px) ≈ 206 × p(µm) / f(mm)   ·   champ de vue = dimension du capteur (px) × e

Exemples : une caméra à pixels de 3,76 µm au foyer d'un 200/1000 mm donne 206 × 3,76 / 1000 = 0,77″/px ; avec un réducteur ×0,63 (focale 630 mm) on passe à 1,23″/px. Sous 1″/px on est « sur-échantillonné » (le drizzle est inutile) ; au-delà de 2–2,5″/px, le drizzle ×2 gagne vraiment en détails (chapitre 4.4).

3.3 Catalogue Gaia et focale automatique

  • 🌐 Générer le catalogue Gaia pour ce champ (focale + capteur) télécharge une seule fois (Internet requis) les étoiles couvrant le champ de vue de votre profil, et mémorise le CSV comme catalogue par défaut. C'est ce catalogue que le solveur interne et la photométrie utilisent.
  • 🔍 Déterminer la focale automatiquement résout une image prise avec votre matériel puis calcule f = 206 265 × pixel / échelle. Pratique après un changement de réducteur ou une distance de caméra modifiée : chargez une image, donnez le RA/Dec du centre (formats « 10:25:03 ou 156.26 » acceptés), cliquez, et la focale du profil se remplit.
Astuce. Le profil se décline aussi en suggestions : le niveau de pollution lumineuse (Bortle) et la taille de pixel orientent notamment les réglages de débruitage et de drizzle. Si vous changez de matériel, dupliquez le profil plutôt que de l'écraser — vous conserverez les deux chaînes de traitement.

4. Ciel profond — les opérations dans l'ordre

Chaque section ci-dessous correspond à un groupe de l'onglet Ciel profond (et à une étape de la figure 1). Réglez chaque groupe en suivant l'aperçu live, puis lancez la chaîne complète avec ▶ Traiter (pleine résolution) et exporter… quand tout est en place.

4.1 Étape ① — Charger les images brutes

Groupe « 1. Images brutes (FITS/TIFF/PNG/RAW) » : Ajouter… sélectionne toutes les poses unitaires (lights) en une fois, Vider réinitialise la liste. Pour une caméra couleur one-shot (OSC), la Matrice de Bayer est lue automatiquement depuis les RAW ; sur les FITS déjà debayerisés, vérifiez-la (RGGB est la plus courante). Toutes les images doivent provenir du même matériel, à la même température et au même gain.

4.2 Étape ② — Construire les masters (les « verres correcteurs » de la session)

Groupe « 2. Calibration — création des Masters ». Quatre champs, quatre rôles :

MasterVolumes conseillésÀ quoi il sert
Bias50–100 (pose la plus courte)Retire le signal électronique fixe et le bruit de lecture
Dark20–50, même pose et même température que les lightsRetire le signal thermique (point chauds, amp-glow)
Flat20–30, au même pointage (ou panneau)Retire vignettage, poussières, sensibilité inégale
Dark-flat15–20, même pose que les flatsRetire le signal thermique des flats eux-mêmes

Les masters sont construits en interne par combinaison robuste des frames (médiane) puis appliqués à chaque light : le dark est mis à l'échelle et le flat normalisé automatiquement. Un dark à la mauvaise température (ou pose) est la première cause de « noise fixed » résiduel : prenez les darks la nuit même, capteur à la température des lights.

4.3 Étapes ③+④ — Calibration et défauts

La calibration s'exécute automatiquement dans la chaîne dès que des masters sont fournis. La correction des défauts vient juste après (groupe « 10. Pixels défectueux — carte & colonnes/lignes mortes », la place est indiquée sur le bouton : Corriger (après calibration)). Deux voies :

  • Détection auto (master dark/flat) — la plus simple : les pixels systématiquement chauds dans le master dark et froids dans le master flat sont repérés et corrigés par voisins ; cochez Colonnes/lignes pour traiter aussi les défauts colonne/ligne (amp-glow CMOS).
  • Carte fournie — si votre constructeur ou logiciel fournit une bad-pixel map (FITS/PNG/TXT), pointez-la avec Carte (FITS/PNG/TXT) :.

4.4 Étape ⑤ — Alignement et drizzle

Groupe « 3. Alignement & Drizzle ». Trois méthodes, de la plus rapide à la plus puissante :

MéthodePrincipeQuand la choisir
Phase (translation+rotation)Corrélation de phase entre framesPetites séries, champ stable, rapidité
Étoiles (similarity)Appariement de motifs d'étoiles (astroalign), similitude complèteSéries longues avec rotation du champ — le choix par défaut en ciel profond
Plate solving + distorsions (poly)Détection d'étoiles puis ajustement polynomial de leurs positionsGrands champs, longue focale, optique qui distord (réducteurs, bretelles) : l'ajustement est itéré avec rejet des paires aberrantes
  • Tenir compte de la rotation du champ : cochez dès que la monture n'est pas parfaitement polaire ou que la série s'étale sur des heures.
  • Drizzle (Sans / ×2 / ×3, Pixfrac ≈ 0,6–0,8) : rééchantillonne pendant l'accumulation en exploitant les micro-décalages entre frames. Utile si e > 2″/px ou si l'échantillonnage est serré au pixel près ; coût : mémoire et temps de calcul proportionnels à l'agrandissement. À 0,8″/px, restez sur « Sans ».
Astuce. En cas d'appariement décevant avec la méthode « poly » sur très peu d'étoiles, revenez à « Étoiles (similarity) » : l'ajustement polynomial réclame au moins ~20 étoiles bien réparties pour un degré 3.

4.5 Étape ⑥ — Empilement : quel algorithme ?

Groupe « 4. Empilement ». Les sept algorithmes partagent le même but — accumuler le signal, rejeter les écarts — mais pas le même compromis :

AlgorithmeComportementUsage recommandé
Sigma-clipping (défaut)Rejette les pixels qui s'écartent de σ fois la médianeLe bon choix universel (σ = 2,5–3)
MoyenneSimplicité, meilleur S/B théoriqueSéries très propres (labo, longue pose calme)
MédianeRejette tout ce qui n'est pas répétéPeu de frames, satellites fréquents
WinsoriséRejet doux : les extrêmes sont bornés, pas supprimésSéries moyennes, peu de frames à sacrifier
Rejet min/maxRetire la plus claire et la plus sombreDépannage rapide, N > 10
Linear fitAjuste une droite par pixel et rejette les résidusGrandes séries, ciel variable (brume, lune)
MAD clippingRejet fondé sur l'écart absolu médian, robuste aux valeurs extrêmesSéries polluées de trains de satellites

Le champ Sigma : règle l'agressivité du rejet (3,0 pour commencer ; 2,5 si des traces subsistent). Le classement qualité des frames (scores de netteté/luminosité, utilisé par le mode planétaire) est également disponible au niveau du noyau pour les chaînes scriptées (chapitre 10).

4.6 Étape ⑦ — Gradient et fond de ciel

Groupe « 5. Traitement (fond, denoise, déconvolution) ». Le Gradient modélise le fond (pollution, lune, veilleuse) et le retire :

  • Polynôme 2D avec son Degré (2–3) : le cas général, très stable.
  • RBF (thin plate) avec ses cases (10–12) : s'adapte aux fonds irréguliers (coins lumineux, halos de lampadaires).
  • Soustraction (le plus courant) ou Division (quand le défaut est un vignettage multiplicatif).

Procédez doucement : un gradient bien réglé laisse un fond plat et sombre sans creuser les grands nébulosités. En pratique, contraignez d'abord la zone d'échantillonnage (cases) plutôt que le degré.

4.7 Étape ⑧ — Débruitage et déconvolution

Dans le même groupe : le Denoise propose Non-local means (naturel, le plus utilisé ; force 0,3–0,5), Bilatéral (protège les bords) et Ondelettes (contrôle multi-échelle). La déconvolution (Richardson-Lucy) affine les détails : Déconv. itérations : 10–20 avec un σ de PSF ≈ 1–1,5 px — par petites touches, et toujours après le débruitage léger : déconvoluer un stack bruité amplifie le grain.

4.8 Étape ⑨ — Couleur : calibrer, neutraliser, déverdir

Groupe « Calibration couleur & neutralisation », à utiliser dans cet ordre :

①Calibration couleur (fond ciel) — équilibre R/G/B sur le fond du ciel (méthode type Siril).
②Neutraliser le fond — fait tendre le fond vers le gris neutre ; le Percentile fond : choisit la population de pixels « fond » (2–5 %).
③SCNR vert (OSC) — supprime la dominante verte des caméras couleur.
④Calibration photométrique des couleurs (étoiles Gaia) — l'affinage le plus juste : les couleurs sont calées sur les étoiles réelles du catalogue (nécessite la plateforme astrométrie du chapitre 9).

4.9 Étape ⑩ — L'IA locale, au bon endroit de la chaîne

Groupe « 6. IA locale » : choisissez la Tâche (denoise / background / sharpen / superres / satellite) et le Fournisseur. Trois voies existent, du plus simple au plus intégré :

VoieContenuInstallation
Outils externes (résultats professionnels)GraXpert (denoise, fond IA), StarNet2/DeepSNR (Cosmic Clarity : usage manuel, non automatisable)Gratuits ; renseignez leurs chemins via Configurer les outils IA (chemins)…
Modèles ONNXVos modèles .onnx déposés dans models/ai/ (+ JSON optionnel : tâche, taille d'entrée, chevauchement, échelle)pip install onnxruntime ; GPU utilisé automatiquement s'il est disponible
Algorithmes classiques intégrésNLM, bilatéral, médiane, ondelettes ; Richardson-Lucy ; polynôme/RBF ; Hough + inpainting ; LanczosRien à installer

Placement dans la chaîne : le débruitage IA remplace (ou complète) l'étape ⑧, après le gradient ; la super-résolution est la toute dernière opération avant export ; la suppression de satellites se fait de préférence sur les frames ou sur le stack avant finition.

4.10 Étape ⑪ — HDR : fusionner plusieurs empilements

Groupe « 7. Composition HDR (plusieurs empilements) » : empilez séparément chaque lot d'expositions (par ex. 300 s et 60 s), ajoutez chaque résultat avec Ajouter exposition…, puis Fusionner HDR (algorithme de Mertens) : le cœur des étoiles et les bras externes restent détaillés sur la même image.

4.11 Astrométrie et exécution finale

Le groupe « 9. Astrométrie locale » (plate solving, photométrie) est décrit en détail au chapitre 9 — il se règle après l'empilement, sur l'image finale. Quand toute la chaîne est réglée : ▶ Traiter (pleine résolution) et exporter… exécute calibration → défauts → alignement → empilement → traitements dans le bon sens, puis propose l'export. Le bouton Exporter l'image… ré-exporte ensuite sans tout recalculer.

Rappel. L'aperçu applique un étirement automatique pour vous montrer les données linéaires — c'est un affichage. Le fichier exporté reste linéaire tant que vous n'avez pas traité la tonalité dans l'onglet Finition (chapitre 8) : conservez le stack FITS 32 bits comme archive maîtresse.

5. Tuto d'exemple ① — traiter M51 de A à Z

Scénario. Une nuit de printemps en banlieue (Bortle 5), Newton 200/1000 mm au foyer, caméra couleur ASI533MC (pixels 3,76 µm). Vous avez posé 30 × 300 s sur M51 (plus 30 bias, 30 darks de 300 s, 25 flats, 15 dark-flats). Soit 2 h 30 de poses à aligner et empiler. Les dossiers sont organisés ainsi : lights/, darks/, flats/, darkflats/, bias/.

5.1 Préparer (une seule fois)

1.Onglet Configuration. Créez le profil « Newton200-ASI533 » : caméra 3,76 µm, −10 °C, matrice RGGB ; télescope 200 mm d'ouverture, f = 1000 mm ; mode Ciel profond ; Bortle « Banlieue (Bortle 5-6) ». L'échantillonnage calculé affiche 0,77″/px — pas de drizzle nécessaire. 💾 Enregistrer…
2.Catalogue Gaia. Toujours en Configuration, cliquez 🌐 Générer le catalogue Gaia pour ce champ : le CSV couvrant ~0,5° autour de M51 est mémorisé comme catalogue par défaut (Internet, une seule fois).

5.2 Traiter (onglet Ciel profond)

3.Brutes. Ajouter… → sélectionnez les 30 fichiers de lights/. Bayer : RGGB.
4.Masters. Pointez chaque dossier dans le groupe 2 (Bias : bias/, Dark : darks/, Flat : flats/, Dark-flat : darkflats/).
5.Défauts. Cochez Détection auto (master dark/flat) + Colonnes/lignes. En aperçu, aucune colonne brillante ne doit subsister sur une frame calibrée.
6.Alignement. Cochez Tenir compte de la rotation du champ (monture non parfaitement polaire sur 2 h 30) ; Méthode : Étoiles (similarity) ; Drizzle : Sans.
7.Empilement. Algorithme Sigma-clipping, Sigma 3,0. Un trio de satellites a traversé le champ ? Passez à MAD clipping ou σ = 2,5.
8.Traitement. Gradient Polynôme 2D, Degré 3, Soustraction — le fond doit devenir plat, M51 intacte. Denoise Non-local means, Force 0,45. Déconvolution : 12 itérations, σ = 1,2 (les bras de M51 se détaillent sans halo sombre).
9.Couleur. Calibration couleur (fond ciel), puis Neutraliser le fond (percentile 2 %), puis SCNR vert si une dominante verte subsiste sur les étoiles.
10.IA (optionnel). Tâche denoise, fournisseur GraXpert, force modérée — l'aperçu live juge de l'effet sur le fond.
11.Astrométrie (optionnel). Groupe 9 : catalogue par défaut pré-rempli, RA centre « 13:29:52 », Dec centre « +47:11 » , Rayon 0,5 → Plate solving. L'échelle résolue doit retomber à ~0,77″/px : sinon, votre focale réelle diffère — utilisez la focale automatique de l'onglet Configuration.
12.Exécuter. ▶ Traiter (pleine résolution) et exporter… → exportez M51_stack.fits (FITS 32 bits flottant). Durée indicative sur un ordinateur courant : quelques minutes pour 30 frames de 9 Mo.

5.3 Finition et archives

13.Onglet Finition (commune). Chargez le stack : montez Gamma (courbes) pour révéler les bras spiraux, +contraste léger, Masque flou (force 0,4, rayon 1,8) sur le noyau désormais maîtrisé. Recadrez (X,Y,L,H) et exportez : TIFF 16 bits pour la retouche, PNG 8 bits pour le web, FITS conservé en archive.
Ce que vous devez vérifier à chaque étape. Après calibration : le fond d'une frame affichée « étirement auto » est sans taches fixes. Après alignement : les étoiles sont rondes aux quatre coins. Après empilement : le bruit a nettement chuté. Après gradient : le fond est plat et gris, sans quartier lumineux. Si un contrôle échoue, revenez au groupe correspondant — c'est tout l'intérêt de l'ordre des opérations.

6. Planétaire — les opérations dans l'ordre

L'onglet Planétaire suit la figure 2. Sa logique diffère du ciel profond : la matière première est une vidéo dont seules quelques dizaines de frames valent la peine, et la cible tourne.

6.1 Étape ① — Charger la source

Groupe « 1. Source : vidéo SER/AVI/MP4 ou images » : basculez Vidéo (SER/AVI/MP4) / Images (APN/FITS/TIFF) puis Charger la source…. Le SER est le format à privilégier à l'acquisition (métadonnées complètes, pas de compression) ; les MP4/AVI de caméras ou de smartphones sont aussi acceptés, de même que les éclipses/lune en fichiers images.

6.2 Étape ② — Le classement qualité, cœur du mode

Groupe « Classement : ». Chaque frame reçoit un score, et seules les meilleures entrent dans l'empilement :

CritèreCe qu'il mesureÀ choisir quand…
Netteté (Registax)Énergie des contours (détails fins)Cas général lunaire/planétaire
LuminositéStabilité d'expositionVidéos avec fluctuations (auto-exposition)
Mixte (AutoStacker)Combinaison des deuxSeeing instable, nuit tourmentée

Le pourcentage (%) détermine la sélection : gardez 10–30 % les mauvaises nuits, 25–50 % les bonnes. Trop généreux, le « voyant » se fige dans le stack ; trop sévère, le bruit remonte.

6.3 Étapes ③+④ — Dérotation et alignement fin

Groupe « 2. Dérotation & alignement ». La Dérotation du champ compense la rotation propre de l'image pendant la vidéo : auto calcule le taux depuis les données de la séance, manuelle impose un taux en °/min (utile au-delà de ~3 min sur Jupiter à grande focale ; en dessous d'une minute, laissez la dérotation désactivée). Intervalle frames : précise la cadence si elle n'est pas lue dans l'en-tête. L'Alignement des couleurs (R/B sur G) recale les canaux des caméras couleur — à activer si les bords frangés de violet/vert apparaissent. L'Algorithme : se choisit selon la cible :

AlgorithmeCible idéale
Phase (rapide)Planètes pleines, bonne luminosité, quick look
Limbe (précis)Jupiter/Saturne/Mars — suit le limbe, robuste en bout de focale
Étoiles (large champ)Grand champ lunaire avec étoiles, ou scènes en fichiers

6.4 Étape ⑤ — Empilement planétaire

Groupe « 3. Empilement » : Moyenne, Médiane, Sigma-clipping, Moyenne (meilleurs %), et surtout AutoStack (AS!-style) — l'approche AutoStakkert! : score de qualité par frame, sélection des meilleures, alignement par points du champ. Avec un stack_percent de 50–75 %, c'est le réglage recommandé.

6.5 Étape ⑥ — Les ondelettes : la « loupe Registax6 »

Groupe « 4. Ondelettes (style Registax6) — aperçu live ». L'image empilée est décomposée en 6 couches de détails, de la plus fine (Couche 1 (fins)) à la plus large (Couche 6 (larges)). Chaque couche a son gain :

  • Couche 1 : granulation, micro-détails — gain 1,3–1,5 pas plus (amplifie aussi le bruit).
  • Couches 2–3 : bandes, continents lunaires — gain 1,2–1,3, le « bon » niveau habituel.
  • Couches 4–6 : structures larges — gain 1,0 (ne touchez pas au début) ; le résidu règle le contraste global.
  • Débruitage (ondelettes Registax) : 0,2–0,4 pour absorber le grain réveillé par les couches fines ; Réinitialiser les couches repart de tout à 1,0.
Méthode. Poussez la couche 1 jusqu'à voir du bruit, puis revenez en dessous d'un cran : vous venez de trouver votre maximum. Les anneaux de Saturne prennent surtout dans les couches 2–3 ; le limbe de la Lune, dans la couche 4.

6.6 Étapes ⑦+⑧ — Couleurs, aberration chromatique, IA

L'Aberration chromatique (correction radiale) corrige les franges R/B qui fuient autour du centre (forte au Newton + barlow) : Rouge : et Bleu : se règlent en quelques essais à l'aperçu. Les fausses couleurs (groupe 7) transforment une image solaire N&B (H-alpha) en palette Solaire (orange), Inferno, Magma, Plasma, Viridis ou Turbo. L'IA locale (groupe 5 : denoise, sharpen, superres) s'applique après les ondelettes — la super-résolution toujours en dernier.

6.7 Étape ⑨ — Le film stabilisé

Groupe « 6. Film stabilisé (aligner + recadrer) & export » : la Recadrage commun automatique (anti-« danse ») aligne toutes les frames sur un recadrage commun — le film ne tremble plus et la rotation du globe devient visible. Réglez Taille crop : (0 = auto), FPS :, le conteneur (MP4 / AVI (MJPG) / GIF) et la Qualité, puis 🎬 Créer le film…. Idéal pour animer la rotation jovienne sur 1–2 h de clips ou une éclipse lunaire.

6.8 Exécuter et rejouer

▶ Tout traiter (classement→empilement→ondelettes…) enchaîne toute la chaîne en pleine résolution, puis Exporter l'image… écrit le résultat. Le groupe « 8. Séquence & batch (style Registax) » mémorise tous vos réglages : 💾 Enregistrer la séquence (tous les réglages), Charger une séquence (modifiable)…, et ▶ Batch SER : empiler toutes les vidéos d'un dossier… avec Frames max/SER : pour borner chaque vidéo — l'objet du chapitre 10.

7. Tuto d'exemple ② — une nuit sur Jupiter

Scénario. Jupiter à 40° de haut, seeing moyen. Newton 200/1000 + Barlow ×2 (focale effective 2000 mm), caméra ASI662MC. Vous avez filmé un clip SER de 90 s à ~110 fps (≈ 9 900 frames). Objectif : un stack net + un film de 6 s montrant le globe.

7.1 Traitement pas à pas

1.Source. Onglet Planétaire, Vidéo (SER/AVI/MP4) → Charger la source… → le SER. L'aperçu montre la première frame.
2.Classement. Netteté (Registax), garder 25 % (seeing moyen). La courbe de classement affichée vous indique où tombe la qualité.
3.Dérotation. Clip de 90 s : laissez la dérotation désactivée (rotation imperceptible).
4.Alignement. Algorithme Limbe (précis). Alignement des couleurs (R/B sur G) coché.
5.Empilement. AutoStack (AS!-style), % 75 des frames classées. Résultat attendu : un globe lisse, les bandes équatoriales nettes.
6.Ondelettes. Gains 1,4 / 1,2 / 0,9 / 1,0 / 1,0 / 1,0 (couches 1→6), Débruitage 0,3. La Grande Tache Rouge se détache sans halos ; si le bord du limbe « accroche », réduisez la couche 1.
7.Chromatisme. Franges violettes sur le limbe ? Aberration chromatique : Rouge +2, Bleu −2 (valeurs d'exemple à affiner à l'aperçu).
8.IA (optionnel). sharpen puis superres (fournisseur ONNX ou outil externe) pour un agrandissement propre.
9.Film. Recadrage commun coché, Taille 300 px (0 = auto), FPS 24, MP4, Qualité haute → 🎬 Créer le film… : la turbulence devient lisible image par image, le globe reste fixe.
10.Exécuter. ▶ Tout traiter (classement→empilement→ondelettes…) puis Exporter l'image… (PNG 16 bits pour garder la dynamique).

7.2 Aller plus loin : plusieurs clips, plusieurs heures

Filmez un clip de 60–90 s toutes les 15 minutes pendant 2 h : chaque clip donne un stack (étapes ci-dessus), et le film stabilisé d'un lot de stacks révèle la rotation du globe. Quand vos réglages sont stables, enregistrez-les (💾 Enregistrer la séquence) et laissez le ▶ Batch SER empiler la soirée entière d'un seul clic — le JSON scripts/batch_planetaire_ser.json fourni avec l'application montre la structure attendue (classement « Netteté (Registax) » 75 %, alignement « Limbe (précis) », AutoStack 90 %, ondelettes 1,3/1,2/1,0…).

Piège classique. Fusionner dans un même empilement des clips étalés sur plus de 3–5 minutes à grande focale : la rotation jovienne brouille les détails les plus fins. Empilez clip par clip, la dérotation ne compensant que le champ, pas la rotation du globe elle-même.

8. Finition (commune) et export des fichiers

8.1 L'onglet Finition : la « salle de retouche » type GIMP

L'onglet Finition (commune) travaille sur une image chargée — le stack des autres onglets ou n'importe quel fichier — et regroupe trois familles d'outils, dans l'ordre où vous les rencontrez :

①Tonalité (style GIMP). Luminosité, Contraste, Saturation, Gamma (courbes) et Balance des blancs R/G/B. C'est ici que l'image linéaire du stack devient visible : le Gamma est votre outil d'étirement manuel (1,5–2,5 typiquement).
②Géométrie. Recadrer X,Y,L,H ; rotations Aucune/90°/180°/270° ; Miroir horizontal/vertical ; Appliquer. Recadrez tardivement : une opération géométrique n'est pas réversible.
③Netteté / filtres. Masque flou (force + rayon) : la touche finale sur les détails, à petits réglages (0,3–0,6 / 1–2 px) après tout le reste.
④Recalcul pour augmenter la résolution. Lanczos ×2, Lanczos ×3 ou IA (ONNX superres) — à placer juste avant l'export final, jamais avant la netteté.

L'histogramme (panneau Histogramme) accompagne chaque réglage : c'est lui qui montre quand le fond « décolle » du bord gauche sans y être collé.

8.2 Exporter sans perdre la qualité

Format d'exportProfondeurUsage
FITS (32 bits flottant)Float32Archive maîtresse, échanges avec d'autres logiciels ; le WCS résolu est inscrit dans l'en-tête
TIFF 16 bits16 bitsRetouche externe, impression
PNG 8 / 16 bits8–16 bitsWeb, sans perte
JPEG 95 %8 bits compresséPartage rapide (réseaux)

Ordre conseillé : terminer la chaîne en 16 bits, exporter le maître FITS, puis décliner les variantes de partage. Un JPEG créé trop tôt dans la chaîne devient un plafond de qualité dont on ne revient pas.

8.3 Séquences batch (esprit Registax) dans la finition

Le groupe « Séquences batch (enregistrer & rejouer) » capture votre chaîne de finition : ＋ Ajouter l'étape courante mémorise les réglages de chaque groupe dans la liste, ▶ Appliquer au lot (dossier)… rejoue la séquence sur toutes les images d'un dossier (FITS/TIFF/PNG/XISF), Charger… / Supprimer gèrent les séquences enregistrées. Détails et exemples JSON au chapitre 10.

9. Astrométrie : plate solving et photométrie

9.1 Deux solveurs 100 % locaux

  • astrometry.net (bouton Plate solving du groupe 9, si l'option est cochée en Configuration) : installez le paquet + les fichiers d'index une fois ; c'est le plus robuste, notamment pour les grands champs.
  • Solveur interne : détection d'étoiles (photutils), appariement de motifs contre votre catalogue CSV (ra,dec,mag en degrés — Gaia par la méthode du chapitre 3), puis ajustement WCS TAN (astropy). Il suppose un centre approximatif connu (RA/Dec + Rayon du groupe 9) et un champ sans distorsion optique forte.

Le formulaire attend les coordonnées sous deux formes — « 10:25:03 ou 156.26 » — et le Rayon (deg) délimite la zone de recherche. Une fois résolu, le WCS est inscrit dans l'en-tête FITS à l'export : vos fichiers deviennent géoréférencés pour tous les autres outils.

9.2 Photométrie d'ouverture

Photométrie → CSV mesure chaque étoile du catalogue dans l'image (ouverture photutils), calibre le zéro de magnitude sur les étoiles de référence et exporte un CSV (x, y, flux, mag). Utilisations : contrôle d'échantillonnage, suivi de transparence, préparation de courbes de lumière.

9.3 Photométrie différentielle

Photom. différentielle → CSV mesure votre cible par rapport à un ensemble d'étoiles de comparaison du catalogue : le zéro instrumental et l'extinction atmosphérique s'annulent, et le résultat s'exprime directement Δmag ± erreur. C'est la méthode de référence pour les exoplanètes en transit et les étoiles variables — tout se calcule localement, sans service en ligne.

Réglages d'ouverture. Si les magnitudes dérivées s'écartent du catalogue, agrandissez légèrement le rayon d'ouverture ou vérifiez l'échantillonnage résolu par le plate solving : une échelle erronée décale toutes les ouvertures.

10.2 Le noyau en Python pur (sans interface)

Toutes les fonctions sont appelables en script — pour un plan d'action nocturne ou un ordinateur sans écran. L'essentiel (extrait de GUIDE_SCRIPTS.md, à lancer depuis le dossier de l'application avec export PYTHONPATH=.) :

# Batch de finition sur un dossier
from astroforge.core import sequence as Q
seq = {"mode": "image", "ops": [
    {"op": "gimp_tone", "params": {"contrast": 0.1, "sat": 1.1,
                                    "usm_amount": 0.5, "usm_radius": 1.5}},
    {"op": "denoise", "params": {"method": "Non-local means", "strength": 0.4}}]}
Q.run_batch_image(seq, "entree/", "sortie/")

# Batch planétaire : toutes les vidéos SER d'un dossier
seq = Q.load_sequence("scripts/batch_planetaire_ser.json")
Q.run_batch_ser_chain(seq, "videos/", "empiles/", max_frames=200)
# Pipeline ciel profond scripté : calibration -> drizzle -> gradient -> denoise
from astroforge.core.image_io import load_image, save_image
from astroforge.core import calibration as C, registration as R
from astroforge.core.stacking import stack
from astroforge.core.drizzle import drizzle_stack
from astroforge.core.gradient import extract_gradient
from astroforge.core.restoration import denoise

cal = [C.calibrate(load_image(p), mb, md, mf) for p in lights]
ref = cal[len(cal) // 2]
shifts = [R.phase_corr(ref, im)[:2] for im in cal]
img, _ = drizzle_stack(cal, shifts, scale=2, pixfrac=0.7)   # drizzle ×2
img, fond = extract_gradient(img, "Polynôme 2D", 3, 12, 2.5, "Soustraction")
img = denoise(img, "Non-local means", 0.5)
save_image("resultat.fits", img)
# Astrométrie : catalogue, focale auto, photométrie (internet pour le catalogue)
from astroforge.core import equipment as EQ, astrometry as A
from astroforge.core.image_io import load_image

EQ.make_gaia_catalog(156.25, 19.75, 0.6, "profiles/gaia_champ.csv", mag_limit=15)
img = load_image("m51.fits")
res = A.solve_image(img, catalog_path="profiles/gaia_champ.csv",
                    center_ra=156.25, center_dec=19.75)
focal = EQ.focal_from_scale(pixel_um=3.8, scale_arcsec_pix=res["scale_arcsec_pix"])
tab = A.aperture_photometry(img, wcs=res["wcs"], catalog_path="profiles/gaia_champ.csv")
tab.write("photometrie.csv", format="csv")

Les opérations de séquence disponibles côté script (Q.OPS) couvrent la tonalité, le débruitage, la déconvolution, les satellites, les palettes, la super-résolution et l'appel IA. Pour un lancement nocturne : nohup python3 mon_script.py > log.txt 2>&1 &. Chaque fonction lourde accepte un rappel progress (fait, total) pour l'avancement.

11.2 Les bons réflexes d'une nuit

  • Avant la nuit : profil d'équipement à jour (température du capteur !), catalogue Gaia généré si vous changez de champ.
  • Pendant : darks à la température des lights ; flats le soir ou au panneau ; clips planétaires courts (60–120 s).
  • Après : traitez d'abord une petite sous-série pour valider la chaîne, enregistrez la séquence, puis lancez le lot complet — éventuellement la nuit suivante en batch.

11.4 Limites connues (à connaître avant de chercher un bug)

  • Le drizzle utilise un noyau carré (translation + petite rotation) — version simplifiée du drizzle de DrizzlePac.
  • Le solveur interne suppose un champ sans distorsion forte et un centre approximatif : pour de très grands champs, préférez astrometry.net.
  • XISF : lecture des images non compressées et zlib (pas LZ4/Huffman) ; écriture Float32 non compressée.

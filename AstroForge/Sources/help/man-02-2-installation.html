2. Installation

2.1 Prérequis

  • Python 3.10 ou plus récent (Windows, macOS ou Linux).
  • Les paquets de requirements.txt : PySide6, numpy, scipy, opencv-python, astropy, Pillow, matplotlib.

2.2 Installation standard

python -m venv .venv
# Windows : .venv\Scripts\activate    Linux/macOS : source .venv/bin/activate
pip install -r requirements.txt
python main.py

2.3 Scripts de lancement tout-en-un

launch.bat (Windows, double-clic possible) et launch.sh (Linux/macOS) créent l'environnement virtuel, installent les dépendances manquantes puis lancent le logiciel.

2.4 Exécutable autonome

build_exe.bat   (Windows)   →  dist\AstroForge\AstroForge.exe
./build_exe.sh  (Linux/mac) →  dist/AstroForge/AstroForge

Ces scripts utilisent PyInstaller et embarquent les interfaces. main.py --selftest vérifie une installation sans ouvrir la fenêtre.

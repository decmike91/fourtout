9. Dépannage et limites

SymptômeCause probable / solution
Plate solving échoueRA/Dec centre approximatif erroné, rayon trop petit, catalogue Gaia non généré pour ce champ — ou générez le catalogue depuis l'onglet Configuration
PCC : « moins de 5 étoiles appariées »WCS absent ou catalogue sans BP/RP — régénérez le catalogue (v1.5+)
Alignement poly : « appariement insuffisant »Images trop peu alignées entre elles — faites d'abord un alignement phase, ou utilisez la similitude
IA : « aucun modèle ONNX »Déposez un .onnx dans models/ai/ ou configurez un outil externe (pip install onnxruntime)
RAW non lupip install rawpy
DrizzleNoyau carré avec pixfrac (pas DrizzlePac) ; prévoir un dithering entre les poses
XISFLecture non compressé, zlib, LZ4 et Zstandard (pip install lz4 zstandard)
Interface en anglais incomplèteLes éléments des listes déroulantes et certains messages du journal restent en français (ils servent de valeurs internes)
GPU non utiliséInstallez CuPy adapté au pilote (pip install astroforge[gpu]) puis cochez « Accélération GPU » dans Configuration ; sinon calcul processeur

1. Installer et lancer AstroForge

1.1 Ce que fait AstroForge

AstroForge est un logiciel de traitement d'images astronomiques écrit en Python, qui fonctionne entièrement en local (aucun envoi de vos images sur Internet). Il s'organise en quatre onglets, visibles en haut de la fenêtre :

OngletRôleMatière première
Ciel profondCalibration, alignement, empilement, gradient, débruitage, IA, astrométrieFichiers FITS/TIFF/PNG/RAW : des dizaines de poses unitaires
PlanétaireClassement qualité, dérotation, alignement, empilement, ondelettes, film stabiliséVidéos SER/AVI/MP4 ou images APN
Finition (commune)Tonalité type GIMP, géométrie, netteté, recalcul, exportUne image déjà empilée, de n'importe quel mode
ConfigurationProfil d'équipement (caméra, télescope), catalogue Gaia, focale automatiqueLes caractéristiques de votre matériel

L'onglet Configuration nourrit les trois autres : le profil y détermine le catalogue d'étoiles, la taille de pixel et le mode par défaut. On le remplit une seule fois, au début du chapitre 3.

1.2 Installation pas à pas

① Installer Python — il faut Python 3.10 ou plus récent. Sous Windows, cochez « Add Python to PATH » pendant l'installation.

② Créer un environnement et installer les dépendances — dans un terminal, depuis le dossier d'AstroForge :

python -m venv .venv
# Windows :  .venv\Scripts\activate        Linux / macOS :  source .venv/bin/activate
pip install -r requirements.txt

③ Options recommandées — pip install rawpy si vous voulez charger les RAW d'appareil photo (CR2/CR3/NEF/ARW/DNG…), et pip install onnxruntime pour les modèles d'IA locaux.

④ Vérifier l'installation — python main.py --selftest contrôle tout le noyau sans ouvrir l'interface ; python tests/smoke.py exécute la batterie complète de tests.

⑤ Lancer — python main.py. En pratique quotidienne, préférez les lanceurs [launch.sh] (Linux/macOS) ou [launch.bat] (Windows, double-clic possible) : ils créent l'environnement, installent les dépendances manquantes et démarront le logiciel. Pour distribuer un exécutable autonome : [build_exe.sh] / [build_exe.bat] produisent dist/AstroForge.

1.3 Visite guidée de l'interface

Trois éléments reviennent dans tous les modes ; il faut les connaître avant de commencer :

  • L'aperçu live. Chaque groupe de réglages recalcule un aperçu environ 450 ms après votre dernier geste, sur une copie réduite de l'image. Vous voyez l'effet immédiatement, avec la bascule Avant / Après / Côte à côte et un étirement automatique commutable — indispensable pour juger une image FITS, dont les données brutes restent volontairement sombres (voir encadré).
  • Les barres de profils. Chaque groupe (alignement, empilement, traitement, IA, ondelettes, animation…) porte une barre [[profil ▾] [💾 Enregistrer] [↺ Standard]] : le profil Standard contient les valeurs par défaut, et vous pouvez créer vos propres réglages nommés (un JSON par profil, dans profiles/).
  • Les traitements en thread. Les opérations lourdes tournent en arrière-plan : l'interface reste réactive et vous pouvez préparer l'étape suivante pendant qu'une pile se calcule.
Astuce. Les menus Fichier (Quitter, Ctrl+Q) et Aide (À propos) complètent l'interface. Tout est reproductible : chaque chaîne de traitement peut être enregistrée et rejouée en batch — c'est l'objet du chapitre 10.

Formats

Matrices de BayerRGGB, BGGR, GRBG, GBRG — choix manuel, ou automatique pour les RAW

SortieFITS float32, TIFF 16 bits, PNG 8/16 bits, JPEG 95 %, MP4/AVI/GIF (films)
Trois réflexes à prendre dès maintenant. ① L'aperçu est calculé sur une image réduite : le bouton [▶ Traiter (pleine résolution) et exporter…] reste l'arbitre final. ② Les fichiers sont traités en flottant 32 bits sur [0..1] : n'ayez pas peur des valeurs d'aperçu « ternes », c'est normal avant étirement. ③ Enregistrez un profil de paramètres dès qu'une combinaison vous satisfait — vous la retrouverez en un clic la prochaine nuit.
